## Media Implementation Notes

### Video Specifications
- **Format**: MP4 (H.264 codec, AAC audio)
- **Codec Settings**: 
  - Video: H.264, 1920x1080px, 30fps, ~5Mbps bitrate
  - Audio: AAC, 128kbps (silent if muted)
- **Audio**: Always MUTED (user preference respected)
- **Playback**: Autoplay without sound, loop where applicable, respect `prefers-reduced-motion`

### Image Specifications
- **Format**: JPG (quality 85-90) for photos, PNG for graphics with transparency
- **Optimization**: WebP variants encouraged for modern browsers
- **Responsive**: Provide responsive variants (2x retina where needed)

### Placeholder Strategy
- All folders contain placeholder descriptions
- Placeholders use CSS gradient backgrounds and clear labeling
- When real assets arrive, simply replace files
- Component code is asset-agnostic and ready for production files

### Accessibility Requirements
- All videos must have captions/subtitles
- Video descriptions for accessibility section essential
- Alt text required for all images
- Audio must never autoplay (already muted)
